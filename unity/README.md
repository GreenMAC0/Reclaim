# ReClaim Unity projects

Use **ReClaimNeighborhood** for the current editable game. Add that folder in Unity Hub and open with Unity 6000.6.2f1. Open `Assets/ReClaim/ReclaimNeighborhood.unity`, then press Play. Arrow buttons and WASD/arrow keys move the character. Click the Game view to focus keyboard input.

The project includes Assets (with metadata), pinned Packages and ProjectSettings. Unity regenerates Library and other local caches. Normal Play-mode reloads are enabled and controls reconnect on enable. The ReClaim scene is selected in build settings.

`ReClaimStarter` is the earlier minimal prototype, retained for reference.

This is a local simulation. Practice does not record verified drops. Unity source is not yet exported or embedded in the web app; the website still uses its browser simulation. A Unity web build and integration are separate work. Unity AI requires your own account/access; no account credentials are included.
